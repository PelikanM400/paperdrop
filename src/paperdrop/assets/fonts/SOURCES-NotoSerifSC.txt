No subsetting, instancing, name editing, or glyph removal. The upstream license
specifies no Reserved Font Name. Original notices are retained in the font and
adjacent OFL file. This font remains licensed under OFL, not the app's MIT license.

Coverage verified after reopening the WOFF2:
- 31,058 glyphs; 30,928 Unicode codepoints; cmap and glyph order equal to upstream.
- Variable weight axis wght 200–900 retained (default 200).
- Every printable ASCII character U+0020–U+007E.
- Entire basic CJK unified ideographs block U+4E00–U+9FFF, not only UI copy.
- All 210 distinct literal Han codepoints found across production .py and ui.html
  at conversion time (including actual status, validation, and error messages).
- Dynamic common Chinese paths, logs, and values use this same complete font.
This is not a claim to cover all Unicode or every rare CJK extension character.
Unsupported glyphs fall through to the preserved bundled Source Han Sans subset
and then the browser's serif fallback; no font is fetched from the internet.

The complete font adds about 11 MB to the distribution, deliberately trading
package size for consistent offline editorial typography and dynamic text support.
The pre-existing Source Han Sans file, license, and guarded URL remain unchanged.
